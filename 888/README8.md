# Отчёт по лабораторной работе

## Менеджер паролей

### Описание

Данное приложение представляет собой менеджер паролей, разработанный на языке программирования Python с использованием GUI-фреймворка Toga.

Программа позволяет:
- добавлять новые пароли;
- просматривать сохранённые данные;
- удалять записи;
- хранить информацию в JSON-файле.

В приложении используется объектно-ориентированное программирование (ООП), а также реализована обработка пользовательских исключений.

### Используемые технологии

- Python 3.12
- Toga
- JSON

### Структура программы

Программа состоит из нескольких классов:

#### PasswordEntry
Класс для хранения информации о сервисе, логине и пароле.

#### PasswordStorage
Класс для работы с сохранением и загрузкой данных из файла passwords.json.

#### PasswordManagerApp
Главный класс графического интерфейса приложения.

### Пользовательские исключения

В программе реализованы собственные исключения:

- PasswordManagerError — базовое исключение;
- EntryNotFoundError — запись не найдена;
- DuplicateEntryError — сервис уже существует;
- StorageError — ошибка работы с файлом.

https://www.python.org/downloads/

Перейти в папку с проектом и выполнить команду:

### Краткая справка

#### Главное окно программы

После запуска приложения открывается окно менеджера паролей.  
В окне находятся:
- поле для ввода сервиса;
- поле для ввода логина;
- поле для ввода пароля;
- список сохранённых сервисов;
- кнопки управления.

#### Кнопка «Добавить»

Используется для сохранения новой записи.

Порядок работы:
1. Ввести название сервиса.
2. Ввести логин.
3. Ввести пароль.
4. Нажать кнопку «Добавить».

После этого запись сохраняется в файл passwords.json и появляется в списке.

#### Кнопка «Просмотр»

Используется для просмотра сохранённых данных.

Порядок работы:
1. Выбрать сервис из списка.
2. Нажать кнопку «Просмотр».

После нажатия появляется окно с:
- названием сервиса;
- логином;
- паролем.

#### Кнопка «Удалить»

Используется для удаления записи.

Порядок работы:
1. Выбрать сервис из списка.
2. Нажать кнопку «Удалить».

После удаления запись исчезает из списка и из файла хранения.

#### Сохранение данных

Все данные автоматически сохраняются в файл:

`text
passwords.json

Благодаря этому информация не удаляется после закрытия программы.
