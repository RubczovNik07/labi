# Отчёт по лабораторной работе

## Задание

**Условие:**  
Создать пакет, содержащий 3 модуля, и подключить его к основной программе. Основная программа должна предоставлять графический пользовательский интерфейс с возможностью ввода параметров и отображения результатов расчёта, а также возможность сохранения результатов в отчёт формата .docx или .xlsx.

## Описание проделанной работы

### 1. Создание структуры проекта

Был создан Python-проект, включающий следующие модули:

appliances.py — содержит описание бытовых приборов и их мощности

calculator.py — выполняет расчёт энергопотребления и стоимости электроэнергии

report.py — отвечает за сохранение результатов в форматы .docx и .xlsx

main.py — основная программа с графическим интерфейсом на GTK (PyGObject)


### 2. Модуль appliances.py

В данном модуле описаны классы бытовых приборов:

Утюг
Телевизор
Стиральная машина

Каждый прибор содержит параметр мощности и возвращает его через свойство power.

### 3. Модуль calculator.py

Модуль отвечает за выполнение вычислений энергопотребления.

Реализован класс EnergyCalculator, который выполняет:

расчёт потреблённой энергии
расчёт стоимости электроэнергии

Формулы расчёта:

Энергия:

E = (P / 1000) × hours × days

Стоимость:

Cost = E × tariff

### 4. Модуль report.py

Модуль обеспечивает сохранение результатов расчёта в файлы:

.docx (Word, через библиотеку python-docx)
.xlsx (Excel, через библиотеку openpyxl)

В отчёт записываются данные:

выбранный прибор
потреблённая энергия
стоимость электроэнергии

### 5. Основная программа (main.py)

Графический интерфейс реализован с использованием PyGObject (GTK 3.0).

Функционал приложения:

выбор бытового прибора через ComboBox
выполнение расчёта энергопотребления
отображение результата в интерфейсе
сохранение отчёта в DOCX и XLSX
ввод параметров:

количество часов работы
количество дней
тариф электроэнергии
